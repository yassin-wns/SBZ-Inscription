Student Management System

Student Management System est une application web de gestion des étudiants inspirée de l’ISET de Sidi Bouzid, développée avec HTML5, CSS3 et JavaScript, sans framework ni backend.

### Fonctionnalités principales

- Tableau de bord : statistiques et nombre d’étudiants.
- Gestion des étudiants : inscription, recherche, modification et suppression.
- Validation : vérification des formulaires et des données.
- Filtres et pagination : recherche par nom, CIN, email, département et année.
- Espace étudiant : inscription en ligne et suivi du dossier.
- Espace administrateur : validation, refus et correction des dossiers.
- Documents : suivi des pièces justificatives et attestation imprimable.
- Contact : préparation des emails et historique des messages.
- Export CSV : exportation des dossiers vers Excel.
- Responsive design : adaptation aux ordinateurs et aux téléphones.

### Technologies utilisées

- HTML5 : structure.
- CSS3 : design et responsive.
- JavaScript ES6+ : fonctionnalités et manipulation du DOM.
- LocalStorage : sauvegarde locale des données.
- GitHub Pages : hébergement du projet.

### Structure du projet

- `index.html` : structure de l’application.
- `style.css` : design et mise en page.
- `script.js` : logique et fonctionnalités.
- `README.md` : documentation.

### Installation et déploiement

Ouvrir `index.html` dans un navigateur ou utiliser Live Server dans VS Code. Pour publier le projet, le déposer sur GitHub puis activer GitHub Pages.

### Limites

Le projet est pédagogique et non officiel. Les données sont stockées localement dans le navigateur. Il ne possède ni véritable base de données, ni authentification sécurisée, ni système d’envoi automatique d’emails.

### Objectif du projet

Mettre en pratique le développement front-end, la validation des formulaires, la gestion des données et le responsive design, tout en réalisant un projet de portfolio pour la formation MDW.
